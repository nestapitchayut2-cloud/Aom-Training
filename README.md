# Aom-Training — OET + PSI Stage 3 Dashboard

แดชบอร์ดเตรียมสอบ OET (Pharmacy) และ PSI Stage 3 ของไอร์แลนด์
ข้อมูลเก็บใน **Google Sheet ของตัวเอง** → บันทึกจากมือถือ เปิดดูจากคอมได้ทันที

🔗 ลิงก์ปลายทาง: `https://nestapitchayut2-cloud.github.io/Aom-Training/`

---

# ⚙️ ติดตั้ง 2 ส่วน (ทำครั้งเดียว ~20 นาที)

## ส่วนที่ 1 — เอาแดชบอร์ดขึ้นเว็บ (5 นาที)

1. เข้า repo **Aom-Training** บน GitHub
2. กด **Add file → Upload files**
3. ลากไฟล์ **`index.html`** (ในโฟลเดอร์นี้) เข้าไป → กด **Commit changes**
4. ไปแท็บ **Settings → Pages** (เมนูซ้าย)
5. หัวข้อ *Branch* เลือก **main** + **/ (root)** → **Save**
6. รอ 1-2 นาที → เปิด `https://nestapitchayut2-cloud.github.io/Aom-Training/`
7. บนมือถือ: เปิดลิงก์ → กด **แชร์ → เพิ่มไปยังหน้าจอโฮม** จะใช้เหมือนแอป

> ตอนนี้ใช้งานได้แล้ว (บันทึกลงเครื่องนั้น) ถ้าพอใจแค่นี้ก็หยุดได้ — ทำส่วนที่ 2 เมื่ออยากให้ข้อมูล sync ทุกเครื่อง

## ส่วนที่ 2 — ต่อ Google Sheet ให้ข้อมูลไม่หายและ sync (15 นาที)

### 2.1 สร้างชีต
1. เข้า https://sheets.google.com → สร้างสเปรดชีตใหม่
2. ตั้งชื่อไฟล์ว่า **`Aom-Training-Log`** ← ⚠️ **ต้องชื่อนี้เป๊ะ** เพื่อให้ Claude ค้นเจอ

### 2.2 ใส่โค้ดหลังบ้าน
3. ในชีตนั้น กดเมนู **Extensions → Apps Script**
4. ลบโค้ดเดิมที่มีอยู่ทั้งหมด → เปิดไฟล์ **`apps-script.gs`** (ในโฟลเดอร์นี้) คัดลอกทั้งหมดมาวาง
5. กดไอคอน 💾 บันทึก
6. เลือกฟังก์ชัน **`setup`** จากเมนูดรอปดาวน์ด้านบน → กด **Run**
   - ครั้งแรกจะขออนุญาต → **Review permissions → เลือกบัญชี → Advanced → Go to (ชื่อโปรเจกต์) (unsafe) → Allow**
   - *(ที่ขึ้นว่า unsafe เพราะเป็นสคริปต์ที่เราเขียนเอง ไม่ได้ผ่านการรับรองของ Google — ปกติ)*
   - เสร็จแล้วจะเห็นชีตชื่อ **Log**, **Mock** และ **Vocab** ถูกสร้างขึ้นมา

### 2.3 Deploy เป็น Web App
7. มุมขวาบน กด **Deploy → New deployment**
8. กดไอคอนเฟือง ⚙️ ข้างคำว่า *Select type* → เลือก **Web app**
9. ตั้งค่า:
   - **Execute as:** `Me` (บัญชีคุณ)
   - **Who has access:** `Anyone` ← ⚠️ ต้องเป็นอันนี้ ไม่งั้นแดชบอร์ดเรียกไม่ได้
10. กด **Deploy** → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### 2.4 เชื่อมแดชบอร์ด
11. เปิดแดชบอร์ด → การ์ด **⚙️ เชื่อมต่อ Google Sheet** → วาง URL → กด **บันทึก URL**
12. ป้ายบนหัวจะเปลี่ยนเป็น **✅ เชื่อมกับ Google Sheet แล้ว**
13. ทำขั้นตอนที่ 11 ซ้ำในทุกเครื่องที่จะใช้ (มือถือแฟน + คอม Ness) — วาง URL เดียวกัน

# 🔒 เรื่องความปลอดภัย

- **ไม่มี token หรือรหัสผ่านใดๆ อยู่ในไฟล์** — Apps Script ทำงานด้วยสิทธิ์บัญชี Google ของคุณเองที่ฝั่งเซิร์ฟเวอร์
- ในไฟล์ HTML มีแค่ **URL ของ Web App** ซึ่งเข้าถึงบัญชี Google ไม่ได้
- **ข้อควรรู้ตามจริง:** URL นั้นเป็น endpoint สาธารณะ ถ้ามีคนได้ URL ไป เขายิงข้อมูลเข้ามาในชีตได้ (แต่**อ่านข้อมูลหรือเข้าบัญชีไม่ได้**) กรณีแย่สุดคือมีแถวขยะให้ลบ — ถ้ากังวลให้เก็บ URL ไว้เฉพาะ 2 เครื่องที่ใช้ อย่าโพสต์ที่สาธารณะ

# 🔧 แก้ไข / อัปเดต

- **แก้เนื้อหาในแดชบอร์ด:** แก้ `index.html` ด้วย Notepad/VS Code → อัปโหลดทับบน GitHub
- **แก้โค้ดหลังบ้าน:** แก้ใน Apps Script แล้วต้องกด **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** (ไม่งั้นโค้ดใหม่ไม่มีผล)
- **เป้าชั่วโมง:** ในไฟล์ `index.html` หาเลข `300` (เป้ารวม) และ `6` (เป้าต่อสัปดาห์)
- **เช็คลิสต์รายสัปดาห์:** หาตัวแปร `var CHKS=[...]`
